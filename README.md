# 다음길

폐업을 고민하는 경기도 소상공인에게 내 상권의 변화를 보여 주고, 폐업 지원·재교육·일자리까지 다음 단계를 한 화면으로 이어 주는 웹앱입니다.
2026 공공데이터 활용 앱 개발 경진대회 출품작입니다.

- 대상 지역: 경기도 31개 시·군 (점포 666,254곳, 2026.9.30 기준)
- 서버·데이터베이스·인증키 없음. 정적 파일만으로 동작합니다.
- 로그인과 개인정보 저장이 없습니다.

## 화면

1. **입력**: 시·군, 행정동, 업종을 고르고 지도에서 가게 위치를 누릅니다.
2. **상권 현황**: 반경 500m 안의 같은 업종 점포 수와 시 평균, 행정동별 분포를 보여 줍니다.
3. **상권 신호**: 경쟁 밀집(시 평균의 1.5배 이상)과 상권 변화(행정동이 '상권축소')로 양호·보통·주의를 정합니다.
4. **다음 단계**: 버티기 / 정리하기 / 다시 일하기 카드
   - 우리 시 소상공인 지원사업, 업종 전환 힌트
   - 점포 철거비 예상 금액 계산기(3.3㎡당 20만 원, 최대 600만 원)
   - 가까운 폴리텍 캠퍼스 3곳의 재취업 과정, 시·군 일자리센터
   - 마감 D-day, 상담용 한 장 요약(글 복사)

## 실행

`web/` 폴더가 앱 전체입니다. 데이터를 `fetch`로 읽기 때문에 파일을 더블클릭하지 말고 간단한 웹 서버로 엽니다.

```
cd web
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포

`web/` 폴더를 그대로 정적 호스팅에 올리면 됩니다.

- **Vercel**: 새 프로젝트 → 이 저장소 선택 → Root Directory를 `web`으로 지정 → Deploy
- **GitHub Pages**: 저장소 Settings → Pages → 배포 폴더에 `web` 내용을 둔 브랜치 지정

## 데이터 갱신

원본 CSV는 용량 때문에 포함하지 않았습니다. 공공데이터포털에서 새 파일을 받아 아래 순서로 다시 만듭니다.

```
pip install pandas

# 1) 상가(상권)정보 경기 CSV → 시·군별 점포 JSON (분기마다)
python scripts/aggregate.py <경기 상가정보.csv> out

# 2) 시·군 파일 + 상권변화지표 + 지원사업 공고 (분기·월마다)
python scripts/build_gg.py out/stores <상권변화지표.csv> <지원사업공고.csv> web/data/gg
cp out/cats.json web/data/cats.json

# 3) 폴리텍 재취업과정 (매년)
python scripts/build_poly.py <재취업과정.csv> web/data/poly.json
```

희망리턴패키지 문구와 마감일은 `web/index.html`의 '다음 단계' 부분에, 일자리센터는 `web/data/jobcenters.json`에 있습니다. 매년 1월 공고가 나오면 고칩니다.

## 계산 규칙과 한계

- 거리: 500m 안팎의 짧은 거리라 위도에 따른 경도 보정을 한 평면 근사로 계산합니다.
- 경쟁 밀집: 내 가게 반경 500m 안 같은 소분류 점포 수 ÷ 시 전체 같은 업종 점포들의 반경 500m 평균. 1.5배 이상이면 해당(초기값).
- 상권 변화: 상권변화지표의 행정동 구분이 '상권축소'면 해당. 행정동 개편으로 602곳 중 546곳만 연결됩니다(부천시 대부분 미연결).
- 업종 전환 힌트: 같은 대분류에서 '반경 안 비중 ÷ 시 전체 비중'이 낮은 업종. 주변에 적다는 뜻이지 수요가 많다는 뜻은 아닙니다.
- 상가정보에는 매출과 유동인구가 없어서 장사가 잘되는지는 판단하지 않습니다.
- 폴리텍 캠퍼스 좌표는 상가정보에서 같은 주소의 점포 좌표를 빌렸습니다(서울정수·반도체융합은 인접 번지).
- 모든 결과는 참고용이며, 지원 신청 전 각 기관 공고 원문을 확인해야 합니다.
