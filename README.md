# 다음길

장사가 어려워진 경기도 소상공인이 **계속할지, 정리할지, 그다음엔 뭘 할지**를 공공데이터로 결정하도록 돕는 웹앱입니다.
에이오디컨설팅 2026 공공데이터 활용 앱 개발 경진대회 출품작(1조 김종준·엄다인)입니다.

- 앱 주소: https://daineom02-source.github.io/daeumgil/
- 대상 지역: 경기도 31개 시·군 (점포 666,254곳, 2026.9.30 기준)
- 서버·데이터베이스 없음. 정적 파일만으로 동작합니다.
- 로그인과 개인정보 저장이 없습니다. 결과는 휴대폰 안에서만 계산하고, 공유할 때도 링크 주소에만 담깁니다.

## 할 수 있는 것

| 단계 | 기능 |
|---|---|
| 1. 진단 | 시·군 → 행정동 → 분야 8개 → 업종 119개 선택, 네이버지도에서 주소 검색이나 핀 끌기로 가게 위치 지정 → 반경 500m 같은 업종 점포 수와 동네 상권 변화로 양호·보통·주의 판정 |
| 2. 선택 | 신호에 따라 먼저 볼 길 추천(버티기 · 정리하기 · 다시 일하기), 지원금 계산기(가게 상황 2~3번 선택 → 받을 수 있는 금액 합계와 무료 지원), 폐업 정리 순서 6단계, 업종 전환 힌트, 가까운 폴리텍 캠퍼스 3곳의 재취업 과정 |
| 3. 연결 | 지원별 신청 버튼과 마감 D-day, 상담용 한 장 요약(글 복사), 결과 링크 공유(상담사가 같은 화면을 봄) |

## 실행

`docs/` 폴더가 앱 전체입니다. 데이터를 `fetch`로 읽기 때문에 파일을 더블클릭하지 말고 간단한 웹 서버로 엽니다.

```
cd docs
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포

GitHub Pages: 저장소 Settings → Pages → Branch `main`, 폴더 `/docs`.

지도는 네이버 클라우드 플랫폼 Maps(Dynamic Map·Geocoding)를 씁니다. 인증키(Client ID)는 NCP 콘솔에 등록한 서비스 URL(`https://daineom02-source.github.io`)에서만 동작합니다. 다른 주소에서 열거나 키에 문제가 있으면 OpenStreetMap → 그림 지도 순서로 자동 대체되어 앱은 그대로 쓸 수 있습니다.

## 데이터 갱신

원본 CSV는 용량 때문에 저장소에 넣지 않았습니다. 공공데이터포털에서 새 파일을 받아 아래 순서로 다시 만듭니다. 앱 코드는 바꾸지 않습니다.

```
pip install pandas

# 1) 상가(상권)정보 경기 CSV → 시·군별 점포 JSON (분기마다)
python scripts/aggregate.py <경기 상가정보.csv> out

# 2) 시·군 파일 + 상권변화지표 + 외부지원사업공고 (분기·수시)
python scripts/build_gg.py out/stores <상권변화지표.csv> <외부지원사업공고.csv> docs/data/gg
cp out/cats.json docs/data/cats.json

# 3) 폴리텍 재취업과정 (매년)
python scripts/build_poly.py <재취업과정.csv> docs/data/poly.json
```

희망리턴패키지 금액·마감일은 `docs/index.html`의 '다음 단계' 부분에, 일자리센터는 `docs/data/jobcenters.json`에 있습니다. 매년 1월 공고가 나오면 고칩니다.

## 계산 규칙과 한계

- 거리: 500m 안팎의 짧은 거리라 위도에 따른 경도 보정을 한 평면 근사로 계산합니다.
- 경쟁 밀집: 내 가게 반경 500m 안 같은 업종 점포 수 ÷ 시 전체 같은 업종 점포들의 반경 500m 평균. 1.5배 이상이면 해당.
- 상권 변화: 상권변화지표의 행정동 구분이 '상권축소'면 해당. 행정동 개편으로 602곳 중 546곳만 연결되고, 나머지는 반경 분석만 보여 줍니다.
- 판정: 두 신호 모두 해당하면 주의, 하나면 보통, 없으면 양호.
- 업종: 상가정보 세부 업종 247개를 사장님들이 부르는 이름 119개로 묶었습니다. 검색은 원래 이름으로도 됩니다.
- 업종 전환 힌트: 같은 분야에서 '반경 안 비중 ÷ 시 전체 비중'이 낮은 업종. 주변에 적다는 뜻이지 수요가 많다는 뜻은 아닙니다.
- 지원금: 2026년 공고 기준 최대 예상치입니다(철거비 3.3㎡당 20만 원·최대 600만 원 등). 실제 금액은 심사로 정해집니다.
- 상가정보에는 매출과 유동인구가 없어서 장사가 잘되는지는 판단하지 않습니다.
- 폴리텍 캠퍼스 좌표는 상가정보에서 같은 주소의 점포 좌표를 빌렸습니다.
- 모든 결과는 참고용이며, 지원 신청 전 각 기관 공고 원문을 확인해야 합니다.
